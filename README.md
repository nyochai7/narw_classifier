# NARW upcall classifier

Binary detection of **North Atlantic Right Whale** upcalls in noisy ocean acoustic
data. Two pipelines are built and compared:

1. **Baseline** — log-mel spectrogram → fine-tuned **EfficientNet-B3** (ImageNet-pretrained).
2. **Audio foundation model** — **Perch v2** embeddings → linear probe, with an
   optional 3-octave pitch shift mapping NARW upcalls (50–250 Hz) into Perch's
   training band (400–2000 Hz).

Dataset: [ICML 2013 Whale Challenge — Right Whale Redux](https://www.kaggle.com/competitions/the-icml-2013-whale-challenge-right-whale-redux) (Kaggle).
Experiment tracking: [Weights & Biases](https://wandb.ai/) (`narw-classifier` project).

## Setup

```bash
git clone git@github.com:nyochai7/narw_classifier.git
cd narw_classifier
curl -LsSf https://astral.sh/uv/install.sh | sh        # install uv if needed
uv sync                                                 # install deps
uv run pre-commit install                               # enable git hooks
uv run wandb login                                      # one-time W&B auth
```

### Dataset

Place `data/raw/{train2/, test2/, sampleSubmission.csv}` (or symlink it). The
Kaggle CLI works (after accepting the rules + verifying your phone on Kaggle):

```bash
uv run kaggle auth login                                # one-time browser OAuth
mkdir -p data/raw && cd data/raw
uv run kaggle competitions download -c the-icml-2013-whale-challenge-right-whale-redux
unzip -q the-icml-2013-whale-challenge-right-whale-redux.zip
unzip -q train2.zip && unzip -q test2.zip
rm *.zip && cd ../..
```

## Running experiments

The four experiments used for the report are wired into a single script:

```bash
bash scripts/run_experiments.sh
```

Or one at a time:

```bash
# Experiment 1: EfficientNet-B3 linear probe (head only), 10 epochs
uv run python -m narw_classifier.training.train \
    model=efficientnet_b3_linear_probe trainer.max_epochs=10

# Experiment 2: EfficientNet-B3 full fine-tune, 10 epochs
uv run python -m narw_classifier.training.train \
    model=efficientnet_b3_full_finetune trainer.max_epochs=10

# Experiment 3 (or 4, swap the pitch shift): Perch v2 linear probe, 100 epochs
uv run python -m narw_classifier.training.extract_perch_embeddings \
    preprocess.pitch_shift_semitones=0          # or 36
uv run python -m narw_classifier.training.train --config-name=perch_config \
    preprocess.pitch_shift_semitones=0 \        # or 36
    trainer.max_epochs=100
```

Each run produces:

- A W&B run with self-describing name (`linear_probe_lr1e-3_bs32_e10_HHMMSS`,
  `perch_v2_linear_shift36_lr1e-3_bs256_e10_HHMMSS`, …)
- A local Hydra run dir `outputs/<date>/<time>/` containing:
  - `.hydra/config.yaml` — resolved config (reproducibility)
  - `checkpoints/{best,last}.ckpt` — `best.ckpt` is the highest-`val/auroc` checkpoint
  - `analysis/` — `predictions.npz`, `pr_curve.png`, `roc_curve.png`,
    `confusion_matrix_t0.5.png`, `summary.json` (auto-generated by
    `EvalArtifactsCallback` at end of training)

To resume / continue training:

```bash
uv run python -m narw_classifier.training.train \
    trainer.max_epochs=20 \
    ckpt_path=outputs/2026-05-23/10-42-17/checkpoints/last.ckpt
```

## Notebooks

- `notebooks/01_data_exploration.ipynb` — class balance, audio metadata, sample
  playback, log-mel + linear-STFT spectrograms of positive vs negative clips.
- `notebooks/02_error_analysis.ipynb` — for a single run dir: PR/ROC curves,
  confusion matrices at multiple thresholds, threshold sweep, per-day error
  breakdown, top-K worst FPs/FNs with spectrograms + audio playback,
  cross-run PR-curve overlay.

## Repository structure

```
.
├── conf/                              # Hydra configs
│   ├── config.yaml                    # top-level config for the EfficientNet baseline
│   ├── perch_config.yaml              # top-level config for the Perch pipeline
│   ├── data/baseline.yaml             # data root, split strategy, batch size
│   ├── preprocess/                    # narw_mel.yaml + perch.yaml
│   ├── model/                         # efficientnet_b3_* + perch_linear_probe
│   ├── trainer/default.yaml           # epochs, accelerator, precision
│   └── logger/                        # wandb.yaml + none.yaml
├── src/narw_classifier/
│   ├── data/                          # NARW dataset, datamodule, manifest, splits,
│   │                                  # Perch audio preprocessing + embedding cache,
│   │                                  # Perch embeddings datamodule
│   ├── models/                        # EfficientNet baseline + Mel preprocessor,
│   │                                  # Perch ONNX embedder + linear-probe LightningModule
│   ├── training/                      # train.py (one entrypoint, both pipelines),
│   │                                  # extract_perch_embeddings.py
│   ├── analysis/                      # predictions, metrics, plots, callback
│   └── utils/                         # filenames, lightning helpers, balanced sampler
├── tests/                             # pytest — every module has tests
├── notebooks/                         # data exploration + error analysis
├── scripts/run_experiments.sh         # runs all four experiments end-to-end
└── CLAUDE.md                          # contract this codebase was built under
```

## Stack

- Python via **uv** (`pyproject.toml`, `uv.lock`)
- **PyTorch** + **PyTorch Lightning** (`pl.LightningModule`, `pl.Trainer`)
- **Hydra** + YAML configs (every parameter overridable via CLI)
- **Weights & Biases** for experiment tracking
- **Lightning AI** cloud for GPU training
- Code style: **Black + isort + flake8** (enforced via `pre-commit`); **nbstripout**
  strips notebook outputs before each commit
- **pytest** — every new function / module ships with meaningful tests
